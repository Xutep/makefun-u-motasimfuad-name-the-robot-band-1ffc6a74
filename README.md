## Name the Robot Band

A [make.fun](https://make.fun/bounty/u-motasimfuad-name-the-robot-band-1ffc6a74) bounty entry. The program writes one funny name for a band made of robots, plus a few words on the band's hit song, to `/output/entry.txt` — under 200 characters, as the bounty requires.

Run it:

```sh
python3 main.py
```

It is deterministic and stdlib-only: every run writes the exact same entry.

## The entry

> THE BLUE SCREENS OF DEATH METAL — hit single ‘Have You Tried Turning Me Off and On Again’

(89 characters)
